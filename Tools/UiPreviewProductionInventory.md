Audit notes: active WinForms surfaces generally have no separate ViewModel; the Revit workspace is WPF MVVM and is covered by `Verify-UiContracts.ps1` command/binding reflection checks. Icon loading is centralized through `UiIconExtension.Load`; ribbon code catches load failures and logs them, preventing a missing resource from aborting ribbon construction. Runtime appearance, tooltips and host interactions remain unexecuted here.
